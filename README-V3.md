# Seydikemer Emlak V3 Yayın Paketi

Çalışan modüller:
- Admin giriş ve oturum kontrolü
- Dashboard
- Sayfalar (Supabase okuma/kaydetme)
- Site Ayarları (Supabase okuma/kaydetme)
- Tüm menü bağlantıları

## Güvenlik SQL'i
Supabase SQL Editor'da `supabase/settings-security.sql` içeriğini bir kez çalıştırın.

## Yerelde test
`.env.local` dosyanızı bu klasöre kopyalayın, sonra:

npm install
npm run dev

## GitHub'a gönderme
`.env.local`, `.next`, `node_modules` klasörlerini göndermeyin.
