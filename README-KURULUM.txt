SEYDİKEMER EMLAK V3 - TEMİZ YAYIN PAKETİ

1) Bu klasörü ayrı bir konuma çıkarın.
2) Eski çalışan projedeki .env.local dosyasını bu klasörün içine kopyalayın.
3) VS Code ile bu klasörün KENDİSİNİ açın. package.json doğrudan sol listede görünmelidir.
4) Terminalde sırayla çalıştırın:
   npm install
   npm run dev
5) Terminalde görünen Local adresini tarayıcıda açın.

Kontrol edilen bölümler:
- Ana sayfa
- Ortak Header ve Footer
- Dinamik mahalle listesi
- Mahalle detay sayfası
- Fotoğraf galerisi
- Google Harita ve haritada aç butonu
- Admin paneli
- Site ayarları / Sayfalar / Mahalleler

Not: node_modules, .next ve .env.local pakete eklenmemiştir.
